Save time

Save tokens
Don't make the model re-read the whole repo each run.
Keep quality
No speed or savings at the cost of a wrong fix.

Memory · it remembers

It doesn't re-solve the same bug from scratch.

Every fix and its findings are saved to a shared memory database — so the next similar issue reuses that work instead of starting over.

Technical summary

Deterministic prep → model draft → human commit gate

Prep · deterministic

Jira fetch/parse, keywords, ripgrep + confidence, git history, memory → one context package.

Draft · model

Agent makes the smallest change; writes analysis / fix / test / diff + one Jira comment.

Command surface

App driven via a CLI that returns data — act, read result, iterate.

Memory

Past fixes saved to .ai_memory/, reused on similar bugs.

Boundaries

Prepare-only. No auto commit / push / merge. Runs locally.

Stack

Python stdlib · Jira REST v3 · ripgrep · git · Claude / Copilot CLI.
